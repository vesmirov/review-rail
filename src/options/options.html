1Create an access token

The extension needs a personal access token with a single scope: read_api — read-only access to MRs, their status, approvals, and comments. The extension can't write anything to GitLab.

read_api ✓ required read MRs, approvals, comments
api ✕ not needed full write access — more than the extension needs
read_user, read_repository, others ✕ not needed never used by the extension

Set the expiration to the maximum your GitLab allows. When the token expires, the extension shows an error — create a new one.

Open the token creation page ↗

Enter your GitLab URL below — a link to the token creation page with the scope pre-selected will appear here.
